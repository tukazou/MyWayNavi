MyWayNavi 開発 引き継ぎメモ（2026-06-28時点）
現在地： デモシナリオの背骨が動作。アプリ→Cloud Run(/chat)→Gemini の本番経路が通り、ハッカソン必須要件（Cloud Run利用）も達成済み。
動いているもの：

地図・現在地追従・車ルート検索（driving）・自動走行デモ
Gemini対話（システムプロンプトはCloud Run側に集約、会話履歴、503リトライ）
チャットUI（地図下半分・吹き出し）
Maps連携（目的地入力→2案提示→ルート選択→案内開始→走行）
バックエンド（FastAPI /chat, /health）をCloud Runにデプロイ、useBackend=trueで本番接続

構成のポイント：

Gemini呼び出しは Cloud Run 経由、Maps(Directions API)はFlutterからCloッ直接
モデルは暫定で gemini-3.1-flash-lite（503回避のため。3.5-flashに戻すのが宿題＝Issue #1）
クレジットは8/18まで300ドル相当が残（コスト懸念なし）
